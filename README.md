<h1 align="center">Pokédex — Android App (Kotlin)</h1>

> 📱 This is a native Android app. It can't be rendered outside an emulator/device, so add a
> screenshot or screen recording here after running it (e.g. `images/screenshot.png`).

## ✨ Features
- Fetches and lists Pokémon from PokéAPI.
- Networking layer under `network/PokeApi.kt` (Retrofit).

## 🚀 How to run
1. Install **Android Studio** (and an SDK / emulator or a physical device).
2. **File → Open** → select this project folder and let Gradle sync.
3. Press **Run ▶** to deploy to the emulator/device.

## 📁 Project structure
```
Pokedex/
└── app/src/main/
    ├── java/...        # activities & logic (Kotlin)
    └── res/            # layouts, drawables, themes
```
